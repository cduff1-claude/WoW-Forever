# WoW Forever addons

Copy each folder into `World of Warcraft/_retail_/Interface/AddOns/` (or wherever your WoW Forever client keeps addons).

Each addon's folder has its own `README.md` with the details.

- **[DruidForeverManabarPlus](DruidForeverManabarPlus/README.md)**: Druid mana bar with the 5-second rule while in forms, shading the mana a shift would cost.
- **[ForeverFiveSecondRule](ForeverFiveSecondRule/README.md)**: 5-second-rule marker on the Player Frame and Personal Resource Display mana bars.
- **[DruidRange](DruidRange/README.md)**: One form-aware range bar for druids, coloured by range to enemy, friendly and dead targets.
- **[ForeverQuestCompleteSound](ForeverQuestCompleteSound/README.md)**: Plays a sound and shows a message when a quest is ready to turn in.
- **[ForeverSequences](ForeverSequences/README.md)**: Windows of spell sequences that fill with colour as you gain the mana to cast them.
